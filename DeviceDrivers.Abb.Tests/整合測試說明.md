# DeviceDrivers.Abb 真機整合測試流程

在已安裝 **ABB PC SDK** 與 **.NET 8 SDK** 的開發機上執行,驗證 `DeviceDrivers.Abb`
類別庫實際連線、讀寫 ABB 機器人的行為。

## 1. 要複製哪些檔案

把以下**兩個資料夾**複製到開發機,且兩者必須**並排放在同一層父資料夾**下
(測試專案以相對路徑 `..\DeviceDrivers.Abb\` 參考類別庫):

```
<任意資料夾>\
├── DeviceDrivers.Abb\          ← 類別庫
│   ├── lib\                    ← 三個 ABB DLL,務必包含
│   ├── Models\
│   ├── *.cs
│   └── DeviceDrivers.Abb.csproj
└── DeviceDrivers.Abb.Tests\    ← 測試專案(本資料夾)
    ├── *.cs
    └── DeviceDrivers.Abb.Tests.csproj
```

> `bin\` 與 `obj\` 不需複製,`dotnet` 會自行重建。第一次建置需連網還原 NuGet 套件
> (xunit 等)。

## 2. 設定環境變數並執行(PowerShell)

```powershell
cd <路徑>\DeviceDrivers.Abb.Tests

# 必填 —— 機器人 IP
$env:ABB_ROBOT_IP = "192.168.0.100"

# 選填 —— 要測讀寫的 RAPID 變數位址,格式 task/module/variable
# 未設定則對應的讀寫測試會自動略過
$env:ABB_TEST_BOOL_VAR   = "T_ROB1/MainModule/testFlag"
$env:ABB_TEST_NUM_VAR    = "T_ROB1/MainModule/testNum"
$env:ABB_TEST_STRING_VAR = "T_ROB1/MainModule/testStr"

# 只跑整合測試
dotnet test --filter "Category=Integration"
```

> 用 `$env:` 設定只在當前 PowerShell 視窗有效,跑完即丟,適合一次性測試。

如要連同 28 個單元測試一起跑,把 `--filter` 拿掉直接 `dotnet test`。

## 3. 測試涵蓋範圍

| 測試 | 內容 |
|------|------|
| `DiscoverControllers_WithIpHint_FindsConfiguredRobot` | 以 IP hint 探索,清單含目標機 |
| `Connect_GetStatus_GetTasks_Disconnect_Succeed` | 連線→狀態快照→列 Task/Module→斷線 |
| `Reconnect_AfterDisconnect_Succeeds` | 斷線後重連 |
| `ReadWriteBool_RoundTrips` | bool 變數寫入→讀回→還原(需 `ABB_TEST_BOOL_VAR`) |
| `ReadWriteNum_RoundTrips` | num 變數讀寫往返(需 `ABB_TEST_NUM_VAR`) |
| `ReadWriteString_RoundTrips` | string 變數讀寫往返(需 `ABB_TEST_STRING_VAR`) |

## 4. 結果判讀

- **全部 Passed** → Phase B/C 真機驗證通過,可進 Phase D。
- **有 Failed** → 多半是 ABB SDK 的讀寫 API 細節需調整(`RapidData.Value` 的 typed
  cast、`Num` 建構子、`Controller.Connect` 多載)。請把完整錯誤訊息回報,以便修正。
- 若整合測試**全部以 0 個執行**顯示 → 代表 `ABB_ROBOT_IP` 未設定(測試早退)。
